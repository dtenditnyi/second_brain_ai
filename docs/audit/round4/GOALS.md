# Round 4 — goals and acceptance criteria

Spec: `docs/audit/PROMPT_ROUNDS_3-5.md` → "Round 4". Order: D → E → API. Tests:
`ai_manager/tests/acceptance/test_round4.py` (+ unit tests per module). Every criterion has a test;
tests start as `xfail(strict=True, reason="R4 G-x")`.

Interfaces (planned): `core/notes_service.py` (read/save/create/delete/rename through
`vault_writer`), `core/ai_providers.py` (Gemini / Ollama / Claude behind one `chat()`),
`core/agent.py` (tool loop + change batches), `core/api_v1/` (token REST API). All writes go
through `vault_writer.vault_apply` (Round 3).
