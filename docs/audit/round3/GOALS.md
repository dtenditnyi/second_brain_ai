# Round 3 — goals and acceptance criteria

Spec: `docs/audit/PROMPT_ROUNDS_3-5.md` → "Round 3". Tests: `ai_manager/tests/acceptance/test_round3.py`
(+ unit tests per module). Order: A → C → B. Every criterion has at least one test; tests start as
`xfail(strict=True, reason="R3 G-x")` and lose the marker when the goal is done.

| Goal | Acceptance criteria | Tests (`tests/acceptance/test_round3.py::…`) |
|---|---|---|
| **G-A1** Markdown in AI answers | 1. marked + DOMPurify + highlight.js served from `static/vendor/`, no CDN, loaded on chat and home. 2. Chat history ships raw Markdown and is rendered by the same client renderer as new answers. 3. Headings, lists, bold/italic, links (`target=_blank`, `rel=noopener noreferrer`), tables, code with highlighting + "Copy" button, inline code, quotes, checkboxes, callouts `> [!type]`, `[[wiki-links]]` → `/notes/?file=…`. 4. Sanitised: `<script>`, `onerror`, `javascript:`, SVG payloads never execute or survive. 5. History and new answers render identically. 6. Status Report renders Markdown. 7. Wide tables/code do not overflow at 320 px. Old XSS tests stay green. | `test_a1_markdown_libraries_are_local_and_loaded`, `test_a1_history_is_rendered_from_raw_markdown`, `test_a1_markdown_features_render_in_chat`, `test_a1_markdown_is_sanitized[*]` (7 payloads), `test_a1_history_and_new_answer_render_identically`, `test_a1_status_report_renders_markdown`, `test_a1_wide_markdown_does_not_overflow_at_320` |

| **G-C3** Single write path | 1.
