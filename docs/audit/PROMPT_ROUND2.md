## 2. Единый скрипт запуска: `start.ps1` (+ обёртка `start.bat`)

В корне репозитория создать PowerShell-скрипт (основной) и `start.bat`, который просто вызывает его (`powershell -ExecutionPolicy Bypass -File start.ps1 %*`), чтобы запускать двойным кликом. Существующий `run_matrix.bat` не удалять, но в README указать, что основной способ — `start.bat`.

Что делает скрипт по порядку (каждый шаг с понятным заголовком и цветным статусом OK/FAIL):
1. Проверки окружения: есть `venv\Scripts\python.exe`, `node`/`npx`, версия Python; предупреждение (не ошибка), если нет `.env` или `GEMINI_API_KEY`/`OLLAMA_HOST` в окружении. **Содержимое `.env` не выводить.**
2. Если нет `ai_manager/audit_copy_db.sqlite3` — скопировать из `db.sqlite3` (только если копии нет; никогда не перезаписывать).
3. Опционально `-Install`: `pip install -r requirements.txt -r requirements-dev.txt` и `npm install`.
4. `manage.py check` и `migrate --settings=ai_manager.settings_local`.
5. Сборка CSS: `npm run build`.
6. **Тесты при каждом запуске:** по умолчанию быстрые (`-m "not e2e and not responsive"`), с ключом `-FullTests` — все (включая Playwright), `-SkipTests` — пропустить. Если тесты упали — остановиться с понятным сообщением и путём к логу (ключ `-Force` — запустить сервер всё равно).
7. Запуск сервера `runserver --settings=ai_manager.settings_local` (порт параметром `-Port`, по умолчанию 8000), открыть браузер на `http://127.0.0.1:<port>` после того, как сервер отвечает.
8. Опции: `-Watch` — в отдельном окне `npm run dev` (Tailwind watch); `-Tunnel` — в отдельном окне `cloudflared tunnel --url http://127.0.0.1:<port>`; `-Docker` — вместо локального режима `docker compose up --build` (с предупреждением, что это прод-конфигурация).

**Логирование каждого запуска:** папка `logs/runs/` (в `.gitignore`), файл `run_YYYY-MM-DD_HH-mm-ss.log` — весь вывод (Start-Transcript или Tee-Object), включая результаты тестов, версию/коммит (`git rev-parse --short HEAD`, ветка), параметры запуска, длительность каждого шага, итог (OK/FAIL). Хранить последние 30 логов, старые удалять автоматически. В конце печатать краткую сводку и путь к логу. Плюс строка-итог в `logs/runs/history.csv` (дата, ветка, коммит, тесты passed/failed, итог).

Описать скрипт и все ключи в README и в `CLAUDE.md` (раздел Commands). Скрипт проверить реальным запуском (с `-SkipTests` и с тестами).
